# 校招看板

> 把招聘信息整理成一张能筛、能搜、能按自己条件排序的看板。
> 数据每天更新一次，打开就是最新的。

**在线地址**：https://la1379.github.io/campus-board/

---

## 这个仓库是什么

给同学（和自己）用的校招信息看板。它解决的是一个问题：

> 小红书上有人天天整理校招清单，但那是图片和表格，没法按「我的专业 + 我的城市」筛。

所以做成网页：**选专业、选城市、按匹配度排**，只看跟你有关的那几条。

## 数据从哪来

| 来源 | 拿到了什么 |
|---|---|
| 京东校招官网 API | 353 条岗位名、城市、专业要求 |
| 腾讯校招官网 API | 1007 条岗位名、城市、事业群 |
| 小红书/公众号清单（人工整理） | 98 条，含截止日、投递方式、评价 |

**不含**：任何需要破解签名或绕过登录墙的数据。字节要 `_signature`（不逆向）、阿里网关 403（不绕过）、小红书要登录（不爬）。

## 怎么用

直接打开网页。第一次进去点「我的档案」，填上你的专业、目标城市、想做的方向，
整张表会按匹配度重排，越靠上的越值得看。

- **匹配度怎么算**：专业 40% + 城市 30% + 方向 30%，关键词命中。
  点分数能看到具体命中了什么。
- **星标**只在你自己浏览器里，别人看不到，换设备也不同步。
- 数据是快照，**投递前到官方渠道复核截止时间**。

## 自己更新数据

桌面双击就行：

- **`打开后台.bat`** —— 启动本地服务并打开 Excel 导入页
- **`发布.bat`** —— 生成网页并推送到 GitHub

或者敲命令：

```bash
npm start            # 本地服务 http://127.0.0.1:7788
npm run deploy       # 生成静态站并发布
```

浏览器打开 `http://127.0.0.1:7788/admin.html`，把 Excel 拖进去就能批量导入。

## 目录

```
├── index.html / app.js / style.css   看板
├── intake.html / intake.js           单条录入（粘贴公告或截图 → 模型抽取）
├── admin.html                        Excel 批量导入
├── server.mjs                        本地服务 + API
├── data/
│   ├── jobs.json                     ← 唯一数据源
│   ├── profile.json                  我的档案（匹配度依据，不入库）
│   └── *-raw.json                    采集原始数据
└── scripts/
    ├── collect-jd.mjs                京东采集
    ├── collect-qq.mjs                腾讯采集
    ├── import-xlsx.py                Excel 导入
    ├── publish.mjs                   生成静态站
    └── deploy.mjs                    发布到 GitHub Pages
```

## 技术选择

**零 npm 依赖。** 只用 Node 内置模块 + 浏览器原生 API，没有构建步骤，没有框架。
三年后还能跑，因为要出问题的东西很少。

Python 只用在两处：数据迁移和 Excel 读取（`openpyxl`）。
